01 / ELEMENTO HTML

Modal nativo

<dialog>

El navegador gestiona la capa superior, el contenido inerte y el cierre con Escape. JavaScript abre la interacción.

Prueba Tab y Escape. Observa que no puedes interactuar con la página de fondo.
Ver código usado 
const dialog = document.querySelector('#confirm');
document.querySelector('#open-confirm')
  .addEventListener('click', () => dialog.showModal());
02 / ATRIBUTO HTML

Popover de acciones

popover="auto"

Abrir, cerrar con Escape y hacer clic fuera no requieren un estado isOpen controlado desde JavaScript.

No es un menú ARIA completo: la navegación con flechas necesita implementación adicional si se requiere.
Ver código usado 
<button popovertarget="actions-panel">Acciones</button>
<div id="actions-panel" popover="auto">…</div>
03 / CSS MODERNO

Anchor Positioning

position-anchor

CSS relaciona un elemento flotante con su referencia sin medir coordenadas en cada scroll o resize.

Este tooltip sigue al ancla
Ver código usado 
.anchor-button { anchor-name: --tooltip-anchor; }
.tooltip {
  position: fixed;
  position-anchor: --tooltip-anchor;
  position-area: top;
  position-try-fallbacks: flip-block, flip-inline;
}
04 / SELECTOR CSS

Estado con :has()

:has(input:checked)

El padre responde al estado de su hijo mediante CSS. No es necesario escuchar el cambio para modificar una clase.

El checkbox cambia el estilo del contenedor, sin JavaScript.

Ver código usado 
.state-card:has(input:checked) {
  background: #2a4050;
  border-color: var(--cyan);
}
05 / WEB API + CSS

View Transitions

startViewTransition()

JavaScript modifica el DOM. El navegador se encarga de capturar los estados visuales y animar el cambio.

Si el usuario solicita reducir movimiento, se cambia el contenido sin animación.

Vista compacta

Este componente muestra información resumida.

Ver código usado 
const update = () => card.classList.toggle('expanded');
if (document.startViewTransition) {
  document.startViewTransition(update);
} else {
  update();
}
